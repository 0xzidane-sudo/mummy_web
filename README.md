# Mummy Maze Pocket — Web Edition

إعادة تنفيذ مستقلة للعبة متاهات مستوحاة من موارد نسخة Android المرفقة.

## التشغيل
- افتح `index.html` مباشرة في متصفح حديث، أو شغّل خادماً محلياً من هذا المجلد:
  - Python: `python -m http.server 8000`
  - ثم افتح `http://localhost:8000`
- تعمل اللعبة على الهاتف والحاسوب، وتستخدم لوحة المفاتيح أو أزرار الاتجاهات أو السحب على المتاهة.

## النشر على GitHub Pages
1. أنشئ مستودع GitHub جديداً.
2. ارفع جميع محتويات هذا المجلد إلى جذر المستودع، مع مجلد `assets`.
3. من Settings → Pages اختر Deploy from a branch، ثم `main` و`/ (root)`.
4. افتح الرابط الذي يظهر في صفحة Pages.

## ما تمت إضافته في هذه النسخة
- استخدام موارد الرسوم الأصلية المستخرجة من APK: الخلفيات، الشعار، الشخصيات، الأرضيات، الجدران، البوابات والكنوز.
- استخدام المؤثرات الصوتية والموسيقى المرفقة.
- 100 مرحلة قابلة للفتح، بتوليد متاهات ثابتة لكل رقم مرحلة (seeded) وتدرج في الحجم والصعوبة.
- حفظ المراحل المفتوحة وأفضل النقاط محلياً عبر LocalStorage.
- مؤقت مضبوط، إيقاف مؤقت، إعادة المحاولة، إعدادات الصوت، دعم اللمس ولوحة المفاتيح.
- الاحتفاظ ببيانات `assets/data/mazes/B-*.dat` وملفات `assets/data/catacombs/*.lvl` الأصلية داخل المشروع.

## حدود المطابقة
هذه ليست عملية نقل للمحرك الأصلي ولا نسخة مطابقة 1:1. ملفات `B-*.dat` الثنائية موجودة ضمن الموارد، لكن تنسيقها الداخلي غير موثق هنا ولم يتم فك ترميزها؛ لذلك المراحل الحالية تُبنى بخوارزمية متاهات مستقلة وحتمية بدلاً من الادعاء بأنها تستخدم خرائط `.dat` الأصلية. كذلك لا تزال بعض تفاصيل الواجهة والحركة وسلوك الأعداء مختلفة عن التطبيق الأصلي.

## ملاحظة الترخيص
الموارد المرفقة من APK أُدرجت لأغراض إعادة بناء نسخة شخصية بناءً على الملفات التي زود بها المستخدم. تحقق من حقوق النشر والترخيص قبل نشر هذه الموارد علناً أو توزيعها.
